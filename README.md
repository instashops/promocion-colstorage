# Promoción Colstorage

Landing en español para mini bodegas en Bogotá. Oferta: **primer mes gratis** para nuevos contratos, sujeta a disponibilidad y condiciones.

## Publicación estática

`index.html` y la carpeta `assets/` son la versión de producción, lista para un alojamiento estático. Mantener ambos juntos.

- Todas las imágenes, el logo original, el favicon, CSS y JavaScript se sirven desde este repositorio.
- Los botones abren WhatsApp con un mensaje prellenado sobre el primer mes gratis.
- La página no enlaza al sitio corporativo ni carga recursos desde él.
- No requiere servidor de API, base de datos ni claves.
- Las imágenes ilustrativas de bodegas, mudanza y candado fueron generadas; no son fotografías de las sedes.

El código está subido al repositorio. Esto no habilita automáticamente GitHub Pages ni cambia un dominio.
